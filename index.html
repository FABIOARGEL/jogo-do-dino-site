01

O que é o Plano Cartesiano?

O plano cartesiano é formado por dois eixos:

↔ Eixo X — Horizontal (esquerda e direita)
↕ Eixo Y — Vertical (cima e baixo)
Origem = (0, 0)

O ponto onde os dois eixos se cruzam

Como funciona?

  • → Aumentar X = objeto vai para a direita
  • ← Diminuir X = objeto vai para a esquerda
  • ↑ Aumentar Y = objeto sobe
  • ↓ Diminuir Y = objeto desce
